## 当前默认设置

| 参数 | 当前值 |
| --- | --- |
| 默认编码码率 | 5 Mbps |
| 浏览器码率选项 | 2、5、10、25 Mbps |
| 帧率选项 | 15、30、60 FPS；默认 30 FPS |
| 虚拟显示总面积 | 25,000,000 像素 |

这些是源码配置，不代表持续带宽、持续 FPS 或端到端延迟。静止画面本身可能产生较低 FPS；网络承载不足时，固定码率仍可能造成卡顿。

## 本轮修改

- 将 README 整理为项目入口，说明功能、快速安装、源码运行、权限和网络限制。
- 将技术文档和任务进度改为按用途分工的 GitHub Markdown 结构，删除过时运行记录。
- 将 install.sh 改为从 GitHub Release 下载并校验当前架构 ZIP，支持 latest、固定版本和指定仓库；程序目标路径为 /usr/local/bin/remotemac，用户配置位于 ~/.config/remotemac，LaunchAgent 后台运行，不打开 Terminal。
- 安装器交互输入访问口令、监听地址和端口；口令保存为 ~/.config/remotemac/password，后台通过 REMOTEMAC_TOKEN 环境变量传入口令。监听默认值为 0.0.0.0:28080。
- 为程序加入 VERSION 构建注入、`-version` 参数、能力接口版本字段和控制面板版本显示；重新构建了前端嵌入资源。
- 虚拟显示尺寸按总面积校验，前端、原生层和指针输入使用一致的面积边界；浏览器 H.264 接收能力参与初始尺寸、重配、帧率和编码帧校验。
- 会话 Cookie 保存访问口令的 SHA-256 摘要，避免特殊字符破坏 Cookie；修正媒体队列超限错误提示并补充边界测试。
